# Security Policy

## Supported versions

Security fixes are developed against the latest code on the default branch. Development builds are not certified for production use.

## Reporting a vulnerability

Do not publish exploitable details, credentials, personal data, or proof-of-concept payloads in public issues. Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature (Security Advisories) when enabled for this repository. If private reporting is unavailable, contact the repository maintainer privately before disclosing details.

Include the affected commit or version, impact, prerequisites, and a minimal reproduction that uses only systems you own or are explicitly authorized to test.

## Safe use

VulnScan is intended for source code and targets that the operator owns or is explicitly authorized to assess. Never use it to scan third-party systems without permission. Uploaded archives are untrusted input; do not expose an instance to the public internet until the production deployment, egress controls, isolation, monitoring, and security review have been independently validated.
