# Roadmap

## Phase 1 — Foundation
- API and dashboard
- Safe ZIP metadata inspection
- Initial tests and Docker development setup

## Phase 2 — Static code analysis
- Semgrep rulesets
- Bandit and Ruff for Python
- Gitleaks for exposed secrets
- OSV-Scanner for dependency advisories
- Normalized findings with evidence, severity, confidence, and remediation

## Phase 3 — Website assessment
- Explicit target authorization and scope
- DNS/IP validation and SSRF defenses
- TLS, headers, cookie, and safe exposure checks
- Rate limits and request budgets

## Phase 4 — AI assistance
- OpenRouter integration
- User-provided API key
- Evidence-grounded explanations; hypotheses clearly labeled
- Redaction and opt-in source context

## Phase 5 — Product features
- PDF/JSON reports
- Audit history and comparison
- Authentication and settings
